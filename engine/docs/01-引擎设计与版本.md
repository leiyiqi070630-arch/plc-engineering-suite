# 01 · 引擎设计与版本

## 1. 定位

引擎是桌面端的**决策与执行中枢**：接收用户意图，规划工具调用，驱动外部工具链完成真实的 IDE 操作，
并把结果结构化成可验收的证据。

```text
桌面端 ──JSON-Lines──► 引擎 ──► 工具路由 ──► execute_tool.exe / TiaOpennessBridge.exe / python
   ▲                     │
   └────── 事件回吐 ──────┘
```

引擎不直接碰 PLC 工程：所有写操作都通过外部执行器完成，引擎负责参数构造、边界校验和结果判读。

## 3. CLI 能力

| 命令 | 用途 |
| --- | --- |
| `bridge` | 长驻 JSON-Lines 会话（桌面端使用） |
| `prompt TEXT` | 单次提问，`--output-format text\|json` |
| `--resume latest` | 续接已存会话 |
| `status` / `sandbox` / `doctor` | 工作区、沙箱、环境健康快照 |
| `agents` / `skills` / `mcp` | 内置 agent、技能、MCP 服务器清单 |
| `system-prompt` | 导出内置提示词（含分段标记） |
| `export [PATH]` | 会话导出为 markdown |
| `dump-manifests` / `bootstrap-plan` | 部署清单与引导计划 |

关键 flag：`--model`、`--permission-mode read-only|workspace-write|danger-full-access`、
`--allowedTools`、`--dangerously-skip-permissions`、`--compact`。

## 4. crate 结构

```
engine/
├─ Cargo.toml            workspace（members = crates/*）
└─ crates/
   ├─ plceng-engine/    入口与生命周期
   ├─ plceng-cli/       REPL、live turn、渲染、诊断、会话
   ├─ runtime/           会话运行时、MCP server/stdio、帧协议
   ├─ tools/             PLC 工具集（327 个 Rust 源文件，最大 crate）
   ├─ api/               模型客户端：流式、上下文审计、多模态预算
   ├─ commands/          slash 命令
   ├─ plugins/           插件装载
   ├─ telemetry/         遥测
   └─ win-proc-guard/    进程守护
```

`tools` 的内部四层（声明 → 校验 → 执行 → 路由）见 `docs/02`。

## 5. 技术栈

| 领域 | 选型 |
| --- | --- |
| 异步 / IO | tokio 1.50、rustls |
| 序列化 | serde_json 1.0、jsonschema 0.51（工具参数校验） |
| 文本处理 | regex-automata 0.4、fancy-regex、aho-corasick、syntect 5.3（代码高亮） |
| 正则引擎 | oniguruma（静态链接） |
| 终端 | rustyline 15 |
| 文档解析 | pdf-extract 0.12 / lopdf 0.42 / zip 2.4 / 自研 OOXML |
| 图形 | png 0.18、svgtypes 0.16、read-fonts + skrifa + harfrust（字体度量与 SVG 渲染） |

字体与 SVG 相关依赖不是装饰：HMI 画面生成需要在离线环境里精确计算文本宽度与控件边界，
避免交付"看起来对但会重叠"的界面。

## 6. 与桌面端的分工

| 关注点 | 桌面端 | 引擎 |
| --- | --- | --- |
| 会话存储 | 落盘 `sessions/<id>/session.jsonl` | 内存中的 turn 状态 |
| 工作区 | 绑定、staging 影子副本、漂移检测、提升 | 只按注入的 workspace root 读写 |
| 模型配置 | 采集、校验、加密存储、本地代理 | 从环境变量读取，不碰密钥文件 |
| 权限 | 设置页选择 | `--permission-mode` 执行 |
| 工具执行 | 提供可执行文件路径 | 构造参数、调用、判读回执 |

这套分工意味着：**换掉桌面端不影响引擎能力，换掉引擎也不影响工程数据**。
