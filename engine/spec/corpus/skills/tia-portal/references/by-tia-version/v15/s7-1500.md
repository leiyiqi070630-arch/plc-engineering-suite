# TIA Portal V15 - S7-1500

> Scope: facts for TIA Portal V15 with S7-1500. Evidence labels preserve the source strength; a fact verified on another release is not promoted to verified here. Source basis: repository generator/runtime contracts, the shared environment reference, and the real-machine evidence cited here.

## Version route

- [route-defined] SIMATIC SD does not exist in V15. This repository has no deterministic V15 LAD XML generator.
- [boundary] V15/V15.1 cannot import V16+ SimaticML documents. Never reuse a newer XML envelope.
- [delivery] V15 LAD uses a V15-native exported document as its editable format.
- [route-defined] SCL/STL/DB/UDT text work uses `tia_openness_write_source`.
- [boundary] The repository's deterministic GRAPH route starts at V16, not V15.
- [scope warning] PublicAPI structural-boundary evidence in the source map was checked for V16-V21. Do not silently promote those version claims to V15.

## Authoring and validation

- [delivery] Start with the requested V15 artifact. Text blocks land together in dependency order; LAD uses a V15-native exported document only when the requested LAD shape needs that format.
- [instruction facts] Ones' complement is `INVERT`, not `INV`. SR is reset-dominant; RS is set-dominant. CTD output is `Q`; QU/QD belong to CTUD. SCL inputs use `:=`, outputs use `=>`.
- [block rule] FC cannot contain a stateful `VAR` section; use formal parameters and `VAR_TEMP`, or use an FB.
- [tag rule] Omit `table_name` to use the localized default tag table; do not assume its English display name.
- [persistence] Save once at meaningful milestones. Temporary learning objects remain unsaved and are deleted and confirmed.
- [evidence limit] V16+ generator envelopes, interface namespaces, PublicAPI boundary sweeps, and GRAPH stamps are not V15 evidence.

## CPU-family rules

- [language] S7-1500 IEC timer instances use `TON_TIME`, `TOF_TIME`, `TP_TIME`, or `TONR_TIME` and invoke their methods.
- [language] CASE supports CHAR/STRING. A FOR counter additionally supports LINT/ULINT.
- [standard OB] A non-optimized standard OB needs at least 20 bytes of local start information. On 1500, the alternative is the optimized-access pragma after the block header.
- [technology objects] PID_Compact is a TO, not merely an instruction. Create the TO body first, read the installed TO type/version, then generate the call. Axis formals use generic `TO_Axis`. Auto-tuning is online-only.
- [hardware] A rack CPU has no onboard process I/O. Unmapped %I/%Q can compile with a warning and then read as silent zero in simulation. Plug and verify real DI/DQ coverage before behavioral claims.
- [runtime] ISO-on-TCP normally uses rack/slot 0/1. Absolute DB access requires PUT/GET permission and a standard DB; optimized DB members need a symbolic channel.
- [Web API] On standard/T/F firmware the official Web API begins at V2.8 for core API/read methods, with later methods added through V3.1. R/H can log in from V3.1 but lacks most browse/program/diagnostic reads. Probe supported methods instead of assuming the table.
- [security] Fresh firmware >= V2.9 can have independent access-level and confidential-configuration defaults. Read both before configuration; do not weaken a real-controller project without explicit intent.

## Simulation and behavioral proof

- [simulation] When simulation is requested, `tia_plcsim_plan` returns the compatible route and package set in one call; environment diagnostics are used when that route reports an environment problem.
- [behavior route] Requested behavioral simulation runs as one continuous compile -> download -> RUN -> stimulus -> observed readback sequence.
- [timed behavior] `tia_plcsim_assert_behavior` combines pulses, delays, latches, and timed assertions in one call when those checks are part of the request.
- [runtime ownership] The selected simulator tool family owns its runtime lifecycle. Trust/UAC/modal cards pause and resume that same operation.
- [network] Standard PLCSIM uses its Softbus route; PLCSIM Advanced exposes TCP/IP when started in TCP/IP network mode.
- [route-defined] V15 S7-1500 uses the installed legacy x86 VPLC route.
- [evidence limit] The sidecar write/read contract is real-machine verified on V16/V17, not V15.
- [legacy capability] Treat Q as the readable verdict surface. Address writes are input-only; symbolic writes require names present in the downloaded program.

## Online values and configuration

- TIA Openness itself cannot read current values. Use the S7 runtime channel for supported absolute addresses and the official Web API for read-only symbolic/optimized data and diagnostics when configured.
- Probe identity/method support first. Batch operations, read mutations back, and report partial writes exactly.
- Web API prerequisites are: enabled web server, API enabled, an authorized web user, downloaded configuration, and explicit handling of a confirmed self-signed certificate.
- PLCSIM Advanced can verify the Web API only in TCP/IP adapter mode with web configuration downloaded; the local source marks this path manual-grounded but not yet end-to-end tool-proven.
- OPC UA/Webserver attributes must be read before write. Safety administration requires an F-CPU plus installed Safety/Openness options; Openness does not compose F-LAD internals.

## Boundaries and recovery

- [recovery] Compile diagnostics, missing dependencies, wrong targets, and failed readback are repaired from the returned state while successful work remains in place.
- [manual gate] Trust/UAC/modal cards pause and resume the same operation after the user action.
- [scope warning] V16-V21 PublicAPI reflection established the detailed no-live-values/no-trace/no-GSD-install/no-CFC boundaries. Re-check V15 before making the same version-specific claim.
