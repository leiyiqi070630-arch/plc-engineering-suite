# 忠实性核对清单与典型场景测试

交付前逐条自检。任何一项不满足 = 动画不合格,回到对应网络重读代码,不许改逻辑迁就动画。

## A. 逻辑来源核对(必须全部来自代码)

- [ ] 每个状态名(St_*)与代码一致,初始状态由代码决定(如 InitDone=0 首周期置 St_Idle)
- [ ] 每个状态转移的条件与代码网络一一对应,能指回 `FB/FC N{编号}`
- [ ] 置位/复位语义正确:SCoil/RCoil 与普通线圈没混用;同一状态同扫描内先置后复位的顺序照抄
- [ ] 网络执行顺序 = 代码顺序,优先级(如下行发车带 !Any_Above)原样保留
- [ ] 时间常数用代码原值(停留 T#5s、超时 T#8s 等),物理模型参数单独标注为"建模值"
- [ ] 中间标志(CallAt/AboveFlag/ServeUp/Arrive 等)的布尔方程与代码一致
- [ ] 输出方程(Motor/Door_Cmd/灯/报警)的使能条件完整,含互锁(!St_Moving_Down 等)
- [ ] 共享 DB 锁存:置位网络(FC)与复位网络(FB)双方都实现了,谁清谁记一致
- [ ] 输入极性正确:EStop 常闭(1=正常 0=急停)、复位脉冲等

## B. 建模假设清单(交付时如实列出)

- [ ] 物理时间参数:层间移动耗时、门开关耗时(文件头集中定义)
- [ ] 传感器阈值:平层检测带、门到位判定点
- [ ] 按钮沿处理方式(脉冲宽度)、速度倍率实现方式
- [ ] 未覆盖的程序部分(安全回路、通信、其他 OB)明确说明

## C. 典型场景测试表(按程序逻辑推演 → 模拟器实测对照)

| 场景 | 预期行为(来自代码网络) | 实测 |
|---|---|---|
| 上电 | InitDone=0 → 置 St_Idle | |
| 空闲 + 单呼叫(上方) | 发车上行,到层停,清锁存,关门回空闲 | |
| 空闲 + 本层呼叫 | OpenHere → 开门,不发车 | |
| 多呼叫同方向 | 沿途逐层停靠(OpenHere 逐层) | |
| 下行召唤 + 轿厢在上方 | 下行发车(!Any_Above 上行优先),逐层停 | |
| 折返 | 上行中本方向无目标、反向有目标 → 反向 | |
| 无目标 | 移动中就近停靠回空闲(N76-79) | |
| 门停留 | 门开到位 → 5s 停留 → 关门 | |
| 关门超时 | 8s 未关到位 → 重新开门 | |
| 门受阻/超载 | 重开(Reopen 条件含 !EStop 分支) | |
| 急停 | 停电机/停关门/置 St_Fault/报警,开门命令被封锁 | |
| 复位 | Fault_Reset & EStop=1 → 清 St_Fault → 置 St_Idle | |
| 找平(如有) | 层间且空闲 → 按 LastDirection 恢复移动至平层 | |
| 中途新呼叫 | 运行中新增呼叫被锁存,顺向/逐层响应 | |

## D. 交付声明模板

```
## 忠实性声明
- 从项目代码读出:块调用关系、状态机、全部网络逻辑、时间常数、DB 锁存
- 建模假设(非代码):一层移动耗时 X s、门速 Y s、平层带 ±Z 层、按钮沿处理
- 未覆盖:xxx(如安全回路、通信块)
- 本动画为逻辑模拟,非 PLC 仿真验证;如需要可接 S7-PLCSIM 对拍
```

## 禁止事项

- 禁止凭网络标题或行业常识推断逻辑,不读代码不开写
- 禁止用"更合理的标准逻辑"替换代码里的实际逻辑(哪怕代码逻辑有缺陷,动画也要忠实呈现,并在交付说明中指出缺陷供用户决定)
- 禁止用装饰性动画掩盖逻辑缺失;画面可以简单,状态与转移必须完整可见
