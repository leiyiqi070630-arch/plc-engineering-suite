# PLC 程序 → 真实逻辑 HTML 模拟动画

把真实 PLC 项目变成单文件 HTML 模拟器:能打开、能交互、能对照程序看"它正在执行哪个网络"。

## 铁律

1. **不伪造逻辑**:每个状态转移、输出方程、定时值必须能指回原程序的具体网络。网络标题只是注释,触点/线圈组合才是事实。凭"标准做法"脑补逻辑=伪造,必须用真实代码覆盖。
2. **状态机与 PLC 一致**:状态名(St_*)、转移条件、S/R 语义、网络执行顺序、时间常数(T#5s 就是 5s)照抄。S/R 是锁存不是赋值;一个扫描内先置位后被复位的顺序严格照网络顺序。
3. **画面简约,信息真实**:不做装饰性动画(粒子/辉光默认不要)。真实运行效果不能丢:状态机名、当前值、位置、门、灯、故障、日志(带真实网络编号)。
4. **诚实声明边界**:代码读出的 vs 建模假设的(物理时间、传感器阈值、按钮沿),交付时明确列出;未覆盖部分如实说明。
