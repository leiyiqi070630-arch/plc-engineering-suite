# PLC Code 私有生成器用例库

本库解释本产品生成器的输入、输出及使用边界。它与编译进引擎的工具契约同步，复用 `plc_corpus_find/read` 按需检索。外部厂商资料说明 PLC 语义，本库说明私有生成器如何表达这些语义。

工具卡已经回答的问题无需查库。需要示例时，可查 `source=generators, tool=工具名, query=任务关键词`。返回的第一个小用例完整时可直接使用；其余条目按 path 读取。绑定工程后自动过滤线路和已知 TIA 版本。未确定目标的示例仅作参考。

每个用例包括需求、完整工具输入、前置条件、预期输出、易错点和验证证据。参数通过 schema 不代表 IDE 接受；生成、导入、编译和控制行为验证分别记录。测试工程名称、变量和固定版本必须按真实工程适配。`confirm`、`disposable` 是接口字段，复制示例不会替用户授权工程写入。

标为 negative / 拒绝反例的用例故意包含错误输入，不能作为可写入工程的正例。其 `offline-rejection` 只证明源码拒绝结果的异常种类和诊断路径、期望、实际值与 `rejectionSpec` 完全一致；没有 XML 生成、IDE 写入或运行行为通过的含义。离线维护脚本只执行已列明的接点编译器拒绝检查，意外生成成功或其他异常均不能通过。

维护命令与覆盖范围见 `COVERAGE.md`。维护者修改 cases 后运行 `python scripts/generator_corpus.py index`；契约变化必须审查后显式加 `--accept-contract-changes`。检查命令 `generator_corpus check <本目录>` 对缺失工具、过期 schema/描述、非法输入、未覆盖形状及证据不一致报错。不要手工把验证状态改成成功。

这是可扩展的契约形状和任务用例库，不是全部指令、所有厂商版本和所有控制工况的穷举，也不保证任意模型正确设计控制逻辑。新增能力应同步增加用例及相应证据。
