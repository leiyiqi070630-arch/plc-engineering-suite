# tia_openness_create_project — extended contract

Reference data moved from the resident card on 2026-09-18. Current schema, diagnostic receipts, user scope and target version take precedence; historical measurements are scoped observations. Read only for an unresolved detail.

Create a real Siemens TIA Portal project shell. This creates/opens the TIA project only; it does not add a PLC device or generate blocks. target_directory + project name together must stay under TIA's 143-character project-path cap (a deep path like the drafts directory often exceeds it): the tool auto-shortens the project name to fit and reports project_name_shortened — reuse the shortened project_match verbatim, or pass a short directory such as C:\Users\<user>\Documents\TIA_Projects to keep the full name; only a directory so deep that even a one-character name overflows is refused, with the exact count. When a non-empty folder with the same name as the requested project already exists under target_directory, the target directory is auto-adjusted (the project name is preserved) and the result reports collision_avoided. If this version's Portal is not running while another is, pass open_new_portal_if_needed=true from the start — without it the call fails TIA_NO_RUNNING_PORTAL and costs one retry. On success the result carries project_match (the exact created project name): pass it verbatim to every subsequent call that operates on this project, because the bridge matches fail-closed and refuses rather than silently re-routing to a different open project. Requires confirm=true.
