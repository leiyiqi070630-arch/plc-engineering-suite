# tia_sd_instruction_spec — extended contract

Reference data moved from the resident card on 2026-09-18. Current schema, diagnostic receipts, user scope and target version take precedence; historical measurements are scoped observations. Read only for an unresolved detail.

Look up the minimal plan shape for ONE SD instruction mnemonic (e.g. Add, Move, TON, CTUD, InRange, Sqrt, PID_Compact, TSEND_C, MC_MoveAbsolute): which fields you supply vs. what the generator auto-fills (SrcType/value_type templates, seal-in wires, catalog pragmas, param order/direction), whether it needs an instance, and a copyable example_network. For OR/seal-in/interlock->coil logic, points to the contact_coil network form. Unknown mnemonics return the typed-op index + catalog listing. Local ok:true is shape-level only; tia_openness_import_block_sd compile is definitive. VERSION BINDING (this result is bound, or refused): the parameter names, order and direction come from a compiled-in static catalog whose harvest statement sits in each category table header (tia_openness_tools/sd_patterns/catalog/{basic,communication,extended,technology}.rs L3-6: AUTO-DERIVED from a byte-identical real-machine V21 export) and is looked up by tia_openness_tools/sd_patterns/spec.rs. The lookup is bound to the target version resolved from this workspace (plc-code.project.json opennessVersion, else a verified live probe, else PLC_CODE_LIVE_TIA_VERSION — the same resolution tia_sd_generate_block uses, sd_patterns.rs L18-26) or from an explicit target_tia_version argument, and every result states it in `tiaVersion`, `schemaVersion`, `source` and `versionBinding`. If that target is NOT a version this catalog covers, the call returns ok:false with stage=version-binding and NO parameter table — `unsupported: no V21 instruction contract available for the target version` — because a catalogued shape means the parameters round-tripped against the catalog's own harvest, not that your target exposes them (a real V20 compile refused MC_Power.Enable_Positive/Enable_Negative/Override, MC_Home.Sensor and MC_Halt.Mode). If the target version cannot be resolved at all, the shape is still returned but versionBinding.usableAsTargetContract=false and tiaVersion is "unknown": treat it as a shape to prove, never as a contract for the project. Confirm the parameter names and count with one tia_openness_import_block_sd compile; if that compile reports a catalogued parameter as invalid, read it as this catalog entry not matching this target rather than iterating on the spelling.
