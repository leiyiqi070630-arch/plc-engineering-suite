# tia_environment_report — extended contract

Reference data moved from the resident card on 2026-09-18. Current schema, diagnostic receipts, user scope and target version take precedence; historical measurements are scoped observations. Read only for an unresolved detail.

Read-only health check of everything the TIA and simulation chain needs on THIS machine, answered without starting any of it: installed TIA Portal releases and paths, per-release Openness registration, the Siemens TIA Openness Windows group (membership only activates in a new logon session), S7-PLCSIM per release (V18+ — V16/V17 ship a simulator this product cannot drive), S7-PLCSIM Advanced and its API generation, the classic S7-PLCSIM V5.x COM server for S7-300/400, the Automation License Manager service (stopped = reports missing licence), run-as-administrator compatibility marks, .NET Framework 4.8, npcap, the PLCSIM virtual Ethernet adapter, and the Windows locale. Returns per-item status, who can fix it, the consequence, the next action, and a per-route verdict saying which simulation routes are actually available here. CALL THIS BEFORE the first simulation attempt on an unfamiliar machine, and after any environment-shaped failure. It is the SIMULATION PHASE gate, not a task-starting survey: call it only once the project and CPU exist and a simulation step is next. It starts no TIA Portal, PLCSIM or controller process (the probe is a read-only PowerShell registry walk), needs no administrator rights, and does NOT re-check the bridge whitelist (tia_openness_check_whitelist owns that).
