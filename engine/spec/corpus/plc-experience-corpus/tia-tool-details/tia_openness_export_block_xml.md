# tia_openness_export_block_xml — extended contract

Reference data moved from the resident card on 2026-09-18. Current schema, diagnostic receipts, user scope and target version take precedence; historical measurements are scoped observations. Read only for an unresolved detail.

Read existing TIA blocks or PLC types by exporting real XML. Supply exactly one of block_path or block_paths (multiple selected paths use ONE Portal attachment). Default result includes data.readable.text: SCL source reconstructed from tokens, nested interface/DB declarations with initial values and explicit Remanence, and LAD/FBD connections plus supported contact/coil conditions. A FlgNet network's `<Call>` parts carry `call` inside `wiring.parts[]`: the SCL statement reconstructed from their wired parameters only, where a typed placeholder means that argument is fed by a box/timer output or another part's pin, which this reader does not reconstruct as SCL — and the network itself stays a wiring index (parts/connections/coilConditions), not a full SCL body. Read this text FIRST; no follow-up outline, XML grep or parsing script for information already returned. Complete XML and a readable text file are saved inside the workspace by default. Large views expose truncated + nextOffset for read_file on the readable file; unsupported syntax is explicitly UNPARSED with the XML location. This is a reading view, not runtime validation or an importable replacement source. Single exports retain the network roster and identity; large metadata and full multi-export envelopes are available at resultPath. Network index is 1-based position; id is document-local. To add LAD calls/networks, regenerate the caller using the generator contract and callee_interfaces; do not text-splice FlgNet.
