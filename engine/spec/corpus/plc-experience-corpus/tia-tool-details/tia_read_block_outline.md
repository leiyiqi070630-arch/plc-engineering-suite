# tia_read_block_outline — extended contract

Reference data moved from the resident card on 2026-09-18. Current schema, diagnostic receipts, user scope and target version take precedence; historical measurements are scoped observations. Read only for an unresolved detail.

Read local SimaticML without attaching to TIA: block identity, nested interface/DB declarations with initial values and Remanence, network titles, SCL sourceText and LAD/FBD wiring connections/coilConditions. A FlgNet network's `<Call>` parts carry `call` inside `wiring.parts[]`: the SCL statement reconstructed from their wired parameters only, where a typed placeholder means that argument is fed by a box/timer output or another part's pin, which this reader does not reconstruct as SCL — and the network itself stays a wiring index (parts/connections/coilConditions), not a full SCL body. Network index is 1-based; id is document-local. Unknown syntax is marked incomplete with XML source lines, never empty logic. callsComplete concerns the extracted call index (SCL/STL calls remain unindexed); it does not mean sourceText is unavailable. Coil conditions cover combinational contacts only, not runtime behavior. Prefer a live export's data.readable when already returned; this tool is for existing local XML artifacts.
