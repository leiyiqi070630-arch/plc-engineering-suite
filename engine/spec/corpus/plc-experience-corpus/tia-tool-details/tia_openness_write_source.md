# tia_openness_write_source — extended contract

Reference data moved from the resident card on 2026-09-18. Current schema, diagnostic receipts, user scope and target version take precedence; historical measurements are scoped observations. Read only for an unresolved detail.

Write complete PLC text sources (.scl/.awl/.stl/.db/.udt) into the active TIA Portal project and generate real blocks. REQUIRED input: exactly ONE of source_text (the inline source text) or source_path (a workspace file holding it) — a call with neither is rejected. Mutating; requires confirm=true. device_name is required — a single call is refused up front with the full missing-parameter list and a batched write-source fails at the bridge with BRIDGE_REQUIRED_OPTION_MISSING, even in a project with exactly one PLC (E2E R001). This tool does NOT resolve the only PLC for you (tia_openness_import_block_xml does; only there is device_name optional), so copy devices[].name from tia_openness_list_devices. NOT idempotent per source_name: external sources are append-only — the engine gives every write a unique name so re-writing a block just works; leftover PlcExternalSource objects cannot be listed or deleted (overwrite_external_source ineffective on V16/V17) — do not try to clean them up. overwrite_external_source defaults true. compile_after_generate=true returns the whole-PLC verdict in data.compile without requiring a separate compile call. Generated objects persist if a later batch operation fails.

SCL/DB/UDT grammar (V16-V21): emit one complete FUNCTION_BLOCK/FUNCTION/ORGANIZATION_BLOCK/DATA_BLOCK/TYPE with VERSION : 0.1, declarations, body, and matching END_*. Locals and DB members belong inside VAR...END_VAR or STRUCT...END_STRUCT. SCL uses its own block header rather than STL TITLE/AUTHOR/FAMILY/NAME headers. An FB instance used by an OB lives in a global instance DB and is called as "DBName"(...); multi-instances use #inst(...). Standard OBs need the platform's 20-byte start/local information, while optimized S7-1200/1500 OBs can use { S7_Optimized_Access := 'TRUE' } and may omit VAR_TEMP entirely (E2E R001 compiled Main (OB1) with no VAR_TEMP, 0 errors). IEC instances use TON_TIME/TP_TIME/TOF_TIME/TONR_TIME and CTU_INT/CTD_INT/CTUD_INT, invoked through the instance and read through Q/ET or QU/QD/CV members. Edge/state instances (R_TRIG, F_TRIG, timers) MUST live in the FB's static area — a TEMP instance is re-initialised every scan and never sees the previous edge (E2E R002). The writer prechecks these shapes and returns a targeted diagnostic when the source needs repair.
